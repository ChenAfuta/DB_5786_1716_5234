# Screenshots Directory

Place application screenshots here for documentation purposes.

## Expected Screenshots

1. **01_main_menu.png** - Main menu screen with all navigation buttons
2. **02_table_crud_select.png** - Table view showing SELECT operation
3. **03_insert_operation.png** - INSERT form for adding new records
4. **04_update_operation.png** - UPDATE form with pre-loaded values
5. **05_delete_confirmation.png** - DELETE confirmation dialog
6. **06_queries_screen.png** - Queries screen with results
7. **07_procedures_screen.png** - Functions/procedures execution screen

To capture screenshots:
1. Run the application: `python main.py`
2. Navigate through each screen
3. Perform operations (select, insert, update, delete)
4. Take screenshots of each screen
5. Save them here with the suggested filenames
